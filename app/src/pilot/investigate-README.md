# Сверка фактов двух выбранных разборов

Инструмент сравнивает новый ручной разбор с конкретным сохранённым эталоном:

```
node src/pilot/investigate.mjs 127142 2021
node src/pilot/investigate.mjs 126198 2005
```

Допустимы только эти пары ID; если выбранный эталон перестал быть последним
подтверждённым анализом сделки, запуск останавливается до модели. Выполнение
использует отдельный `runPilotCommand`: база читается только в транзакции
`READ ONLY`, Битрикс ограничен разрешёнными методами чтения, сервер приложения,
очередь и доставка не запускаются. Для транскрибации временно запускается STT
на loopback и выполняются платные запросы Polza. Режим разбора — `silent`.

Отчёт возвращается только после подтверждённого завершения ресурсов. Он содержит
фиксированные категории вердикта и причин, численные сводки использованных
судьёй источников, а также агрегаты по звонкам. Тексты фактов и вердиктов,
записи, имена, ссылки и идентификаторы в результат не включаются.

`candidate_groups` — совпадения точного нормализованного времени и направления
при отсутствии коллизий текущих активностей. Это **не доказательство**, что
сопоставлены один звонок или один файл: старые факты обычно не содержат
`activity_id`. `id_verified_groups` означает только совпавший идентификатор
активности при его наличии, а не доказанную идентичность аудиофайлов.
Неоднозначные группы и несовпадения ID учитываются отдельно.

`old_event_to_transcript_reasons` определяет по фиксированным шаблонам, был ли
старый факт звонка помечен как отсутствие записи, нераспознанная запись или
отсутствие разговора. Счётчик применяется только к кандидатам с совпавшим
временем и направлением, а не к доказанно одному звонку. `lexical_overlap` —
категория пересечения слов в памяти; она не является семантической оценкой.
Сравнение оснований судьи — только признаки упоминаний, а не доказательство
того, почему модель приняла решение.

Результат зависит от актуальной версии данных Битрикса и недетерминированной
модели. Исторический пакет не доказывает, что текущий файл является тем же,
который распознавался ранее; отсутствие совпадения не доказывает ошибку кода.
