# Первичный сбор сделки

`collectDeal({ client, dealId, silent, now, wait })` собирает карточку сделки,
историю стадий и исходные данные коммуникаций. Функция ничего не записывает в
Битрикс и базу. `now` — время в миллисекундах, `wait` — внедряемая задержка для
тестов. По умолчанию используется текущее время и реальные задержки 2 и 4 секунды.

Клиент реализует `await client.request(method, body)` и возвращает полный
конверт ответа Битрикса `{ result, next }`. Метод передаётся без `.json`.
Сетевые ошибки и ошибки Битрикса клиент выбрасывает как исключения. Сборщик
повторяет неудачные запросы до трёх раз, проверяет ответы и страницы, не
записывает тексты исключений и URL в возвращаемые ошибки.

Результат содержит `deal_id`, `silent`, карту `_sources` и
`ready_for_analysis: false`. Статусы:

- `skipped` — исключён ответственный.
- `skipped_by_reason` — техническая причина, `deal_data` содержит дату отказа
  и предыдущую стадию. Поле `_skip_reason_key` содержит причину пропуска.
- `error` — ошибка карточки, справочника, истории или одного из источников.
  Если сделка вышла из отказа, `_step` равен `check_stage`, а `_reason` —
  `not_in_lost_stage`. При ошибке источника карта `_sources` показывает,
  что именно не прочитано.
- `pending_normalization` — карточка и все четыре источника прочитаны.
  Данные в `raw` остаются исходными ответами Битрикса.

`raw` содержит `calls`, `comments`, `tasks`, `chats`, `openline_activities`
и `sessions`. Сессии включают исходную историю и файлы. Сначала запрашиваются
уникальные `SESSION_ID`, затем используется запасной запрос по `CHAT_ID` для
чатов, по которым история с сообщениями не получена.

Сборщик не нормализует сообщения открытых линий, не распознаёт голосовые и
скриншоты, не оценивает поздние записи и не формирует `communications` для
анализа. Эти этапы ещё необходимо подключить. Флаг `ready_for_analysis` всегда
равен `false`, пока весь конвейер не выполнит необходимые преобразования и
проверки. В `raw` могут присутствовать персональные данные и временные ссылки,
поэтому содержимое нельзя выводить в журналы или сохранять в Git.
